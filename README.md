# Student Management System

A responsive Student Management System website developed using HTML, CSS, JavaScript, and Bootstrap.

## Features
- Add student details
- Delete student records
- Automatic grade calculation
- Average marks calculation
- Top score tracking
- Responsive modern UI
- Local storage support

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Project Goal
The project helps manage student information efficiently through a clean and interactive web interface.
